## Найденные недостатки

### Алгоритмические / научные

1. **Аналоги почти дублируют друг друга.** Соседние «концы окна» (например, 2010/2011/2012) делят `lookback−1` темпов роста и `horizon−1` лет исхода. Семь «аналогов» — по сути 2–3 независимых наблюдения, поэтому полоса p10–p90 слишком узкая (24% покрытия вместо 80%). Добавлен параметр `min_separation`.
2. **Только один baseline** (продолжение недавнего темпа). Нет random walk, drift, средних, затухающего тренда. Новый код сравнивает с шестью baseline и показывает, что на реальных данных (ВВП на душу США) лучшим часто оказывается drift.
3. **Метрики:** только MAE/MAPE, без масштабно-независимых (MASE), без теста значимости различий (Diebold–Mariano), без учёта перекрытия окон (91 перекрывающееся 10-летнее окно ≈ 9 независимых).
4. **Нет калибровки интервалов** у baseline и нет честного эмпирического интервала; покрытие считалось только для полосы аналогов.
5. **Ревизионная утечка неустранима архитектурно:** ключ `(indicator, entity, year)` перезаписывается при повторной загрузке, архивных версий данных нет.
6. «Магическая» константа `0.007 * level_gap` без обоснования (сохранена ради совместимости, вынесена в параметр).

### Данные и происхождение

7. `CHECK(value > 0)` и фильтр `parse_row_value` **молча отбрасывают** нули и отрицательные значения (темпы роста, сальдо, индексы демократии могут быть 0).
8. Не хранятся единицы измерения, версия данных у издателя, хеш исходного файла; `imported_utc` перезаписывается.
9. `load_series` возвращает URL только последней строки — если ряд собран из нескольких источников, происхождение теряется.
10. OWID-загрузчик молча берёт **первую** колонку графика, не читает метаданные (единицы, лицензия, первоисточник), не имеет повторных попыток.

### Граф знаний

11. Связи не имеют уровня доказательности, временного лага, альтернативных объяснений; нет проверки, что следствие не раньше причины.
12. События — один целый год, без неопределённости датировки, категории, региона.
13. Тип `documented` требует только непустой URL (что сам README справедливо называет недостаточным).

### Инженерные

14. Монолит в одном файле, нет конфигурации, логирования, миграций схемы.
15. `with sqlite3.connect(...) as con` **не закрывает** соединение (менеджер контекста sqlite3 только коммитит).
16. Нет тестов CLI, загрузчиков, событий/связей.
